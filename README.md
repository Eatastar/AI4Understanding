# AI4Understanding (AI4U)

**AI 辅助个人阅读与知识整理**

AI4Understanding 是一款基于「AI 嵌入式论文 PDF 阅读器」（AI-Embedded Paper PDF Reader）的新产品，目前仍在开发中。读者可以围绕论文或书中的一段原文向 AI 提问，核对回答引用的段落，再把自己的理解整理进个人知识库。我们的目标是打造一套开源的 AI 辅助个人阅读与知识整理体系，在易用性、来源可追溯性和长期使用的稳定性上达到商用水准。

## 目前可以做什么

这个试用版和原版 AI 阅读器在功能上差别还不大，大部分功能的交互和细节也比较粗糙。

- **聊天**时可以自由提问，也可以选中回答中的一句话，针对这句话继续追问。
- **阅读**本地 PDF 或电子书时，可以在原文旁问 AI、翻译选区或写批注，保留问题对应的原文位置。
- 在**个人 Wiki** 中，可以把聊天回答、原文选区和批注整理进条目，编辑文字和公式、链接其他条目，再点来源返回原文。

## Windows 试用版

目前只提供 **Windows x64** 试用包。待产品成熟后，我们会发布 macOS 和 Linux 版本。

1. [下载 v0.1.46-preview.69 的 Windows ZIP](https://github.com/Eatastar/AI4Understanding/releases/download/v0.1.46-preview.69/AI4Understanding-0.1.46-preview.69-Windows-x64.zip)。
2. 右键点击下载的 ZIP，选择「全部解压」。
3. 打开解压后的文件夹，双击 **`AI4Understanding.exe`** 启动。

首次打开可以先试用本地演示模式。要让 AI 回答自己的问题，在工作台右上角打开模型菜单，点「配置 API」添加自己的模型连接。[试用版发布说明与 SHA-256 校验文件](https://github.com/Eatastar/AI4Understanding/releases/tag/v0.1.46-preview.69)

## English

AI4Understanding is a new product built on AI-Embedded Paper PDF Reader and is still in development. Readers can ask AI about a passage in a paper or book, check the sources cited in the answer, and write up what they learned in their personal knowledge base. We aim to build an open-source system for AI-assisted personal reading and knowledge management with commercial-grade usability, source traceability, and long-term reliability.

The preview is still close in functionality to the original AI reader, and much of the experience is rough. You can chat and ask follow-up questions about a single sentence, ask about or translate selected passages in PDFs and ebooks, and bring answers, passages and annotations into a personal wiki with links back to their sources.

**Only Windows x64 is available for this preview.** Download the Windows ZIP, choose **Extract All**, then open the extracted folder and double-click **`AI4Understanding.exe`**. You can explore in local demo mode or configure your own model connection for live answers. We plan to publish macOS and Linux versions once the product is more mature. [Download and release notes](https://github.com/Eatastar/AI4Understanding/releases/tag/v0.1.46-preview.69)
